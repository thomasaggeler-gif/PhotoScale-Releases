Erstinstallation: eine Terminal-Zeile, .command wird von macOS blockiert.

Erstinstallation auf einem anderen Mac: PhotoScale-0.1.2-installieren.zip herunterladen (nicht das Sparkle-Update-Zip), entpacken, Anleitung.txt öffnen. Eine Terminal-Zeile (xattr -cr , Ordner auf das Terminal ziehen), App nach Programme, dann xattr -cr /Applications/PhotoScale.app. Das .command aus dem Internet wird von macOS als «beschädigt» blockiert. Danach kommen Sparkle-Updates ohne Extra-Schritt.
